Interpretation

What the results mean

If the browser baseline is around 30 even with the game absent, 60 FPS cannot be forced by changing a game setting: inspect the device power mode, display refresh settings, browser limits, remote desktop, or foreground throttling. If the baseline reaches at least 55 but Sightline remains around 30, the game is the bottleneck or an old build is loading. If this small WebGL test is slow too, investigate browser GPU acceleration and drivers.

120 FPS requires a browser/display that actually supplies roughly 120 rAF callbacks. Selecting 120 in a menu does not create extra refresh cycles on a 60 Hz display.

For game-specific data, open the game with ?debug, start a match and run window.__sl.performanceInfo() in the browser console. Inspect estimatedRafCallbacksPerSecond, measuredGameFps, simulationCpuMs, and cpuSubmissionMs. Submission time is not GPU execution time.
